# Docs index

These docs describe implemented behavior in the current macOS app unless a file explicitly says it is a proposal or plan. Files under `docs/plans/` are design history and may describe work that is incomplete or intentionally superseded.

- `TROUBLESHOOTING.md`: Common issues and resolutions.

- `DATA_STORE.md`: Storage location, backup, attachment handling, and wipe guidance.
- `FEATURE_MATRIX.md`: Feature availability by app surface.
