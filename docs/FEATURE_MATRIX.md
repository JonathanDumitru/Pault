# Feature matrix

This matrix lists what each current app surface supports. "Pro" means the surface exposes the feature, but access depends on the user’s Pro status.

| Capability | Main window | Menu bar | Hotkey launcher |
| --- | --- | --- | --- |
| View prompts | Yes | Yes | Yes |
| Search prompts | Yes | Yes | Yes |
| Create prompt | Yes | Yes | No |
| Create from template | Yes | No | No |
| Create from clipboard | Yes | No | No |
| Create with AI | Yes (Pro) | No | No |
| Edit title/content | Yes | No | No |
| Rich text editing | Yes | No | No |
| Template variable editing | Yes | No | No |
| Attachment management | Yes | No | No |
| Text/block mode switching | Yes | No | No |
| Copy to clipboard | Yes | Yes | Yes |
| Favorite / unfavorite | Yes | Yes | No |
| Archive / unarchive | Yes | Yes | No |
| Delete prompt | Yes | Yes | No |
| Tag management | Yes | No | No |
| Recently used filter | Yes | No | No |
| Smart collections | Yes (Pro) | No | No |
| Version history | Yes | No | No |
| Analytics | Yes (Pro) | No | No |
| AI assist | Yes (Pro) | No | No |
| Run prompt against provider | Yes (Pro) | No | No |
| A/B testing | Yes (Pro) | No | No |
| Global hotkey access | No | No | Yes |

Notes:
- The launcher currently supports copy workflows only. It does not expose archive, delete, or paste actions.
- The menu bar popover supports lightweight creation and quick management, not full editing.
