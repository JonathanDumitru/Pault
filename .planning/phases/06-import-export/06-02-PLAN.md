    1. Create `Pault/ImportOrchestrator.swift`:
       - `enum ConflictResolution: String, CaseIterable` — skip, overwrite, keepBoth
       - `struct ImportCandidate: Identifiable` — id (UUID), incoming (PromptExportRecord), existing (Prompt?), resolution (ConflictResolution, default .skip for duplicates, .keepBoth for new), isExpanded (Bool)
       - `struct ImportSession` — records: [ImportCandidate], globalResolution: ConflictResolution?
       - `struct ImportResult` — imported: Int, overwritten: Int, skipped: Int, errors: Int
       - `enum ImportOrchestrator`:
         - `static func prepare(jsonURLs: [URL], markdownURLs: [URL], context: ModelContext) -> ImportSession?` — parses all files, fetches existing prompts by UUID for duplicate detection, returns ImportSession
         - `static func parseJSON(at url: URL) -> [PromptExportRecord]` — decodes PromptExportBundle, returns records (both v1 and v2)
         - `static func parseMarkdown(at urls: [URL]) -> [PromptExportRecord]` — parses each via MarkdownFrontmatterParser, converts MarkdownImportRecord to PromptExportRecord for uniform handling
         - `static func applyImport(session: ImportSession, context: ModelContext, promptService: PromptService) -> ImportResult` — loops candidates, applies resolution:
           - skip: continue
           - overwrite: call `promptService.saveSnapshot(for: existing, changeNote: "Before import overwrite")`, then update existing prompt fields from incoming record
           - keepBoth: create new Prompt with `UUID()`, title + " (Imported)", all other fields from record
         - For each imported prompt: resolve tags via `ExportService.resolveTag`, create TemplateVariable records. Auto-detect `{{variables}}` in content via `TemplateEngine.extractVariableNames` and merge with record's templateVariables (frontmatter variables take precedence on name collision).
         - Maintain in-memory `[String: Tag]` cache within the import loop to avoid redundant fetches (per RESEARCH pitfall 4).
         - Call `context.save()` once at end.
         - Return ImportResult with counts.

    2. Create `Pault/ImportPreviewSheet.swift`:
       - SwiftUI `.sheet` view receiving `Binding<ImportSession?>`
       - Header: "Import Prompts" title, count summary ("N prompts, M duplicates"), "Apply to all duplicates" Picker (only shown if duplicates exist)
       - List body: ForEach over session.records — each row shows:
         - Prompt title (bold), tag count, duplicate badge (if existing != nil)
         - Picker for conflict resolution (Skip/Overwrite/Keep Both) — only on duplicate rows
         - Disclosure/expand button on duplicate rows to show inline diff (DiffEngine.diff(old: existing.content, new: incoming.content)) rendered as colored lines
       - Footer: Cancel button, "Import N Prompts" button (count excludes skipped)
       - On import: calls `ImportOrchestrator.applyImport`, dismisses sheet, sets a `@State importResult: ImportResult?` on parent to trigger summary banner
       - Accessibility: `.accessibilityLabel` on each row ("Prompt: title, duplicate" or "Prompt: title, new"), `.accessibilityLabel` on resolution picker, keyboard navigable list
       - Summary banner: after import, show inline non-modal banner at top of ContentView with "N imported, M overwritten, K skipped" — auto-dismiss after 5 seconds or on tap
