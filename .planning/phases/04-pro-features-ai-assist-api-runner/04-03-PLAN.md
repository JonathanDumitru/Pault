**Create Pault/RunTabView.swift:**

Build a new `RunTabView` that composes the full Run tab experience:

```
struct RunTabView: View {
    @Environment(\.modelContext) private var modelContext
    @Bindable var prompt: Prompt
    let config: AIConfig

    @State private var variableValues: [String: String] = [:]
    @State private var isRunning = false
    @State private var streamingText = ""
    @State private var runMetadata: (inputTokens: Int, outputTokens: Int, costUSD: Double)? = nil
    @State private var runTask: Task<Void, Never>? = nil
    @State private var startTime: Date = Date()
    @State private var errorMessage: String? = nil

    @Query private var runs: [PromptRun]  // filtered by prompt
}
```

Layout (stacked vertically in ScrollView):

1. **Variable form:** If `prompt.templateVariables` is non-empty, show a form section with `TextField` for each variable. Pre-fill with `TemplateVariable.defaultValue` if available. Use `ForEach` over detected variables. Label each field with the variable name.

2. **Execute button row:** `HStack` with:
   - "Run" button (`.buttonStyle(.borderedProminent)`, disabled when `isRunning` or no API key configured)
   - "Cancel" button (plain style, visible only during run, calls `runTask?.cancel()`)
   - Model label: small gray text showing current `config.provider.displayName + " / " + config.model`

3. **Streaming response area:** Visible when `isRunning || !streamingText.isEmpty`. Use `ScrollViewReader` with:
   - `Text(streamingText + (isRunning ? "|" : ""))` in `.font(.system(.body, design: .monospace))` with `.frame(maxWidth: .infinity, alignment: .leading)` and padding
   - Invisible anchor `Color.clear.frame(height: 1).id("bottom")` scrolled to on `streamingText` change
   - Blinking cursor: the "|" appended during streaming with opacity animation

4. **Response footer:** Visible when `runMetadata != nil` and run is complete. Display: "{outputTokens} tokens . ~${costUSD formatted to 2 decimal places} . {latency}s". Use `HStack` with small gray `Text`.

5. **Response actions:** When run is complete, show `HStack` with:
   - "Copy" button (copies `streamingText` to `NSPasteboard.general`)
   - "Save as Prompt" button (creates new `Prompt` from response text)

6. **Error display:** If `errorMessage` is set, show red text below execute button with the error.

7. **Run history:** Below the response area, show `RunHistoryView(runs: runs)` filtered to this prompt's runs, sorted by `createdAt` descending.

**Execute logic (`startRun()`):**
1. Pro-gate: Check `ProFeature.isUnlocked(.apiRunner)` -- if not, trigger paywall (pass through binding or closure).
2. Set `isRunning = true`, clear previous `streamingText`, `runMetadata`, `errorMessage`.
3. Resolve variables: substitute `variableValues` into compiled prompt text.
4. Record `startTime = Date()`.
5. Call `AIService.shared.streamRun(prompt: resolvedText, variables: [:], config: config)` (variables already resolved).
6. Iterate stream: on `.token(let t)` append to `streamingText`. On `.metadata(...)` store in `runMetadata`.
7. On completion: calculate `latencyMs = Int(Date().timeIntervalSince(startTime) * 1000)`. Persist `PromptRun` to modelContext with all fields populated (promptTitle, resolvedInput, output, model, provider, latencyMs, inputTokens, outputTokens from metadata).
8. Error handling: catch `AIError.subscriptionRequired` -> set errorMessage. catch `AIError.rateLimited(let r)` -> set errorMessage with retry info. catch `AIError.missingAPIKey` -> show setup prompt. Other errors -> "AI unavailable -- check connection".
9. Set `isRunning = false` on completion or error.

**@Query for runs:** Filter `PromptRun` by `prompt` relationship. Use `init` with `_runs = Query(filter: #Predicate<PromptRun> { $0.prompt?.id == promptID }, sort: \.createdAt, order: .reverse)` or equivalent pattern.

**Update Pault/ResponsePanel.swift:**
Update `startRun()` to consume `AsyncThrowingStream<StreamEvent, Error>` instead of `AsyncThrowingStream<String, Error>`:
- On `.token(let t)`: append to `streamingText` (same as before)
- On `.metadata(let meta)`: store token counts and cost (add `@State private var runMetadata` similar to RunTabView)
- Update `persistRun()` to include `inputTokens` and `outputTokens` from metadata
