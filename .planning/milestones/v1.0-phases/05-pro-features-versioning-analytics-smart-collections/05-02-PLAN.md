  <files>Pault/CopyEvent.swift, Pault/AnalyticsService.swift</files>
  <action>
**CopyEvent.swift:**
1. Add `var eventType: String = "copy"` to CopyEvent (SwiftData-safe default -- existing rows remain as "copy" events, no data loss per research pitfall 4).
2. Add `UsageEventType` enum: `.copy`, `.created`, `.edited`, `.deleted` with String raw values ("copy", "created", "edited", "deleted").
3. Add computed `var type: UsageEventType` (get/set) that maps between raw String and enum -- follows `editingModeRaw`/`editingMode` pattern in Prompt.swift.
4. Add convenience init: `init(promptID: UUID, type: UsageEventType)` that sets promptID, timestamp = Date(), eventType = type.rawValue.

**AnalyticsService.swift:**
5. Add `func recordEvent(_ type: UsageEventType, for promptID: UUID)` that creates and inserts a CopyEvent with the given type. Existing `recordCopy(for:)` should delegate to this with `.copy`.
6. Add `func dailyEvents(days: Int = 30) -> [(date: Date, count: Int)]` that aggregates ALL event types by day for the last N days. Uses Calendar.current to bucket by startOfDay. Returns array sorted by date ascending. Fill in zero-count days for chart continuity.
7. Add `func tokenTotals(days: Int = 30) -> (input: Int, output: Int, hasPartialData: Bool)` that fetches all PromptRun records in the date range, sums `inputTokens` and `outputTokens` via compactMap + reduce. Set `hasPartialData = true` if any runs had nil tokens.
8. Add `func promptIDsRunWith(model: String) -> Set<UUID>` that queries PromptRun where model matches and returns the unique set of promptIDs. (Needed by Plan 05-03 for smart collection model filter.)
9. Wire event recording into existing prompt lifecycle hooks: find where prompts are created (PromptService or views) and call `recordEvent(.created, ...)`. Find where saveSnapshot is called and record `.edited`. Find prompt deletion and record `.deleted`. If the recording sites are in other files (PromptService.swift, views), note those as additional files touched.

**Important:** Keep existing `recordCopy(for:)` signature working as a thin wrapper. Do not break existing call sites.
