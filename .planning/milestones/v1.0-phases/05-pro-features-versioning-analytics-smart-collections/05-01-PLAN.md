**PromptDiffView.swift:**
1. Add `DiffTarget` enum at top of file:
   - `.againstCurrent(PromptVersion, Prompt)` -- existing behavior
   - `.versionToVersion(older: PromptVersion, newer: PromptVersion)`
2. Refactor PromptDiffView to accept `let target: DiffTarget` instead of separate version/prompt params. Add a convenience init that takes `(version: PromptVersion, prompt: Prompt)` mapping to `.againstCurrent` for backward compatibility.
3. Add computed helpers: `leftTitle`, `rightTitle`, `leftContent`, `rightContent`, `leftVersion`, `rightVersion` that switch on `DiffTarget` to extract the correct values. For V2V: left = "Version A (formatted date)", right = "Version B (formatted date)" per CONTEXT.md. Sort so older version is always on the left.
4. Refactor `sideBySideDiffView` to use computed helpers instead of direct version/prompt access.
5. Add synchronized scrolling to side-by-side mode: use `@State private var scrollPosition = ScrollPosition(idType: Int.self)` shared between both ScrollView panels via `.scrollPosition($scrollPosition)`. Wrap in `if #available(macOS 15, *)` guard; fall back to independent scrolling on macOS 14. Use `onScrollPhaseChange` to prevent feedback loops (only propagate during `.interacting` phase) if needed.
6. In V2V mode, show "Restore This Version" button on BOTH panels (not just one). Each button restores that panel's version. Restore flow unchanged: snapshot current state ("Before restore"), apply version content/metadata, snapshot restored state ("Restored from {date}"). The restore needs access to the current Prompt -- add `var prompt: Prompt?` parameter that's required for V2V mode to enable restore (passed from PromptVersionHistoryView).
7. Update `performRestore()` to handle both DiffTarget cases. For V2V, accept a `PromptVersion` parameter indicating which version to restore.
