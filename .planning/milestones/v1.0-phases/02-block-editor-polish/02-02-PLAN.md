Use a separate transferable type for library blocks to avoid conflict with `.onMove` (see research pitfall 2 — use a LibraryBlockTransfer wrapper or check drag source).
    3. Render a 2pt accent-colored Rectangle between blocks when `dropTargetIndex == index`.
    4. Add empty canvas drop zone: when `model.canvasBlocks.isEmpty`, show a dashed border rectangle with guidance text ("Drag blocks here or use Cmd+/ to add") and a `.dropDestination` for library blocks.

    6. Auto-scroll during drag: when drag position is within 60pt of top/bottom edge of the ScrollView, programmatically scroll in that direction.
    7. Add keyboard shortcuts via `.onKeyPress` or keyboard shortcut modifiers:
       - Option+Up/Down: call model.moveOnCanvas for selected block
       - Cmd+D: call model.duplicateBlock for selected block
       - Enter/Return: toggle expand/collapse on selected block
       - Cmd+Shift+E: toggle all blocks expanded/collapsed
       - Cmd+Shift+C: copy compiled prompt to clipboard (post brief toast)
       - Delete/Forward Delete/Cmd+Backspace: remove selected block
       - Cmd+Home/Cmd+End: scroll to first/last block

       - Layered Esc: dismiss palette > picker > help > deselect > collapse

    10. Preserve scroll position when toggling panels.

    3. Dim drag handle opacity when single block (canvasBlocks.count == 1).

    7. Long titles: truncate with ellipsis + `.help()` modifier for hover tooltip.
